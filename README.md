# SWAP QUEST v0.2

元金回収ゲーム用のPWA叩き台です。

## v0.2の変更点
- 高値掴み救出ミッションを削除
- 建値入力を削除
- ポジションの編集機能を追加
- 含み損益、FX会社表示の未決済SWAP、1日SWAP、基準日を後から変更可能
- 基準日から `1日SWAP × 経過日数` を「推定増加分」として自動積み上げ
- 推定現在SWAPと全決済想定に推定増加分を反映
- v0.1と同じlocalStorageキーを使うため、同じGitHub Pagesを上書き更新すれば既存データを引き継ぐ設計
- Service Workerキャッシュ名を `swap-quest-v2` に更新

## 注意
推定SWAPは単純な暦日計算です。実際のスワップ付与は3倍デー・休日・業者ごとのルールでズレます。定期的にFX会社の実績値へ更新してください。

## GitHub Pages更新
既存リポジトリの `index.html`、`manifest.webmanifest`、`sw.js`、アイコンをv0.2のファイルで置き換えてください。
