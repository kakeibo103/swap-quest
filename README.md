# SWAP QUEST v0.3 — ライトテーマ＆利回り表示

## 変更点
- 300万円回収クエストの集計方法と入力を維持
- 明るいベージュ＋グリーンの新デザイン
- 総合損益率（口座資産額合計と実質投入元金合計から算出）
- スワップ単純年換算利回り（登録済みの1日SWAP合計×365÷実質投入元金）
- 設定画面に「実質投入元金」「現在資産」更新欄を追加。普段は現在資産の欄のみ更新。
- 公開コードには口座残高等の個人金額を含めない仕様。個人用の集計ファイルをアプリ内で初回読み込みすると、8項目の手入力が不要
- v0.1/v0.2からのデータ引き継ぎ。LocalStorageキーは **swapQuestDataV1** のまま
- 旧データがある場合、更新時に元データを **swapQuestDataBeforeV03** に一度だけ自動保存（同じブラウザ・同じサイト内）
- PWAキャッシュを v3 に更新。

## データ保存について（重要）
1. **まず旧アプリの「設定」→「バックアップを書き出す」でJSONを保存してください。**
2. GitHub Pages の既存のリポジトリに、このZIP内の `index.html`、`sw.js`、`manifest.webmanifest` と2種類のアイコン画像を上書きアップロードします。旧リポジトリや保存データを削除しないでください。
3. ページの更新後、ポジション・確定損益の履歴・元金回収ゲージが残っているか確認してください。初回はPCのブラウザから確認すると安心です。
4. 初回だけ別添の **swap-quest-PRIVATE-initial-values.json** を、アプリ内の「設定」→「集計値ファイルを読み込む」で読み込んでください。これを **絶対にGitHubへアップロードしないでください**。読み込んだ数字はこのブラウザ内だけに保存されます。
5. 値動きがあったら「ホーム」→「資産額を更新」、または「設定」で現在資産を更新してください。
6. **総合利回りは手動入力した資産額のスナップショットを使います。** 推定スワップを加算すると二重計上になるため自動更新しません。一方、スワップ想定年利回りはポジションに登録した1日SWAPから自動計算します。
7. ポジション内容、毎日の推定SWAP積み上げ、確定損益、バックアップ・復元は従来通りです。

## 免責と補足
- 利回りは累計の単純損益率であり、時間加重収益率や年率換算した実績リターンではありません。出金・追加入金や年をまたぐ取引がある場合は口座ごとの実質入金額を調整してください。
- スワップ想定年利回りは将来の利益を保証しません。実際の付与額・税金・為替差損益によって変動します。
- 「今年の税金見込み」は従来のv0.2の簡易計算を維持しており、**年間の自動仕訳ではありません**。正しい年次税額の計算はFX業者の年間損益報告書などで行ってください。
- 複数端末間でLocalStorageは自動同期されません。データ移行にはバックアップJSONを使ってください。
