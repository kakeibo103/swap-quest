# SWAP QUEST v0.1

元金300万円の回収を、確定スワップだけでなく確定為替損益・未決済スワップ・含み損益・税金まで含めて追跡するPWAの叩き台です。

## 主要機能
- 4口座を初期登録
  - GMOクリック証券（確定型）
  - セントラル短資FX（未決済型）
  - JFX（未決済型）
  - SBI FXトレード（未決済型）
- 確定スワップ / 確定為替損益の入力
- 未決済ポジションの含み損益・未決済スワップを管理
- 税引後の「確定回収率」
- 今すぐ全決済した場合の「全決済想定回収率」
- 高値掴みポジションの「救出ミッション」
- JSONバックアップ / 復元
- PWA対応（ホーム画面追加 / オフラインキャッシュ）

## 注意
税金表示は単純な概算です。損失繰越、他の先物取引との損益通算、必要経費などは計算していません。確定申告用ではなく進捗管理用です。
